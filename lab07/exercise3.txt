    Checkoff Question 3:

    As blocksize increases, performance first improves and then deteriorates, forming an inverted U-shape curve. Initially, larger blocks improve data locality by allowing more work to be done on data while it resides in the fast L1/L2 cache, which efficiently amortizes the fixed overhead of the blocking logic itself. However, once the blocksize grows too large, the working set no longer fits in the cache, leading to capacity misses and cache thrashing. This cache penalty quickly overwhelms the benefits of locality, causing performance to drop. This demonstrates that while caches universally benefit from localized access patterns, there is an optimal blocksize that balances the overhead of blocking against the finite capacity of the cache hierarchy.
